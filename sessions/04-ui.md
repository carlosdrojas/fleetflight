## Goal
A real web UI for FleetFlight, built with Vite + React + TypeScript and no UI kit. It renders **only data it receives** from the CLI's `serve` API (`/api/describe`, `/api/runs`, `/api/runs/<id>`, `/api/cex/<id>`, `POST /api/replay`). Nothing may be hard-coded.
- Until stream 03 exists, serve `fixtures/` through a Vite dev proxy or mock handler.
- `npm run build` outputs to `ui/dist/`, which `fleetflight serve` hosts.

## Screens
Same visual language as the hi-fi: dark, Space Grotesk / IBM Plex Sans / JetBrains Mono, accent #7AA2FF, fail #FF6B57, pass #3DBE8B, warn #E5A63A.
1. **Spec**: from `describe`. Components with their states, injectables, invariants with formulas, assumptions tagged ASSUMED / OUT OF SCOPE, bounds.
2. **Checks**: a run list plus the run detail. Stat tiles, a per-depth bar chart from `stats`, and the invariant table linking to counterexamples.
3. **Counterexample**: the key screen. It must be generic:
   - Build the swimlanes from the snapshot keys (bms, bus, hub, inv, …). Derive segments by grouping consecutive steps with the same value.
   - Scale time from `t_ms`, and draw the deadline and violation window from the counterexample fields.
   - Clicking a step moves the cursor and shows that step's snapshot.
   - Injected moves are marked.
4. **Replay**: pick a SUT version and call `POST /api/replay`. Show per-step match, the hash comparison, and pass / fail.
   - A "Repeat ×N" button runs N replays and draws the determinism grid.
5. **Versions**: replay one counterexample against every SUT version from `describe`, and draw the "fault to stop" bars against the budget.
6. **Regressions**: list `tests/regress` counterexamples, if the API exposes them. Otherwise, show the generated test source for a chosen counterexample.
   - Coordinate through your status file with a CONTRACT REQUEST if you need a new endpoint.
7. **CI**: skip unless time allows. The real GitHub check is better demo footage than a fake one.

## Quality bar
- It must look like the hi-fi and never crash on missing fields: guard everything, and show empty and error states.
- Keep a "MOCK DATA" badge that appears **only** when the payload has `"_fixture": true`.
- Minimum width 1280. Keyboard-accessible buttons. Text contrast ≥ 4.5:1.
